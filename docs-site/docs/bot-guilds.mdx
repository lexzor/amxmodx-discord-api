# Bot Guilds

## Natives

### `GuildChannelExists`

Check if a channel exists in a guild searching by channel ID.

#### Signature

```c
GuildChannelExists(const identifier[], const guild_id[], const channel_id[]);
```

#### Parameters

| Parameter | Description |
|-----------|-------------|
| `identifier` | Bot identifier. |
| `guild_id | Guild`	ID to check. |
| `channel_id | Channel`	ID to search for. |

#### Returns

True if bot it's in guild and channel has been found, false otherwise.

---

### `GetGuildChannel`

Get a guild's channel name and parent id.

#### Signature

```c
GetGuildChannel(const identifier[], const guild_id[], const channel_id[], name_buffer[], name_buffer_len, parent_id_buffer[], parent_id_buffer_len);
```

#### Parameters

| Parameter | Description |
|-----------|-------------|
| `identifier` | Bot identifier. |
| `guild_id | Guild`	ID to check. |
| `channel_id | Channel`	ID to search for. |
| `name_buffer | Buffer`	to copy channel's name in. |
| `name_buffer_len | Buffer`	size for name. |
| `parent_id_buffer | Buffer`	to copy channel's parent id in. |
| `parent_id_buffer_len | Buffer`	size for channel's parent id. |

#### Returns

True if bot it's in guild and channel has been found, false otherwise.

### `EndCreateGuildChannel`

Finalizes channel creation and sends the request to the Discord API.

:::info Note

A response will be sent in OnGuildChannelCreate.
The channel_handle passed here will later be passed to OnChannelCreateEvent.

:::

#### Signature

```c
EndCreateGuildChannel(const identifier[], ChannelHandle:channel_handle);
```

#### Parameters

| Parameter | Description |
|-----------|-------------|
| `identifier` | Bot identifier. |
| `channel_handle` | Channel handle returned by BeginCreateGuildChannel. |

#### Returns

True if the request was successfully sent to the Discord API, false otherwise.

### `OnGuildChannelCreate`

Triggered after a channel create response has been received.

#### Signature

```c
OnGuildChannelCreate(const identifier[], const ChannelHandle:channel_handle, const bool:success, const channel_id[]);
```

#### Parameters

| Parameter | Description |
|-----------|-------------|
| `identifier` | Bot identifier. |
| `channel_handle | Channel`	handle returned by BeginCreateGuildChannel or INVALID_CHANNEL_HANDLE if the channel has not been created by a request sent by EndCreateGuildChannel. |
| `success | True`	if channel has been created successfully, false otherwise. |
| `channel_id | Channel`	id if the channel has been created successfully, empty otherwise. |

### `ChannelFlag`

&gt; Used in SetGuildChannelMemberInt third parameter.

| Member | Value | Description |
|--------|:-----:|-------------|
| `NSFW` | `(1 &lt;&lt; 4)` | NSFW Gated Channel. |
| `VIDEO_QUALITY_720P` | `(1 &lt;&lt; 5)` | Video quality forced to 720p. |
| `LOCK_PERMISSIONS` | `(1 &lt;&lt; 6)` | Lock permissions (only used when updating channel positions). |
| `PINNED_THREAD` | `(1 &lt;&lt; 7)` | Thread is pinned to the top of its parent forum or media channel. |
| `REQUIRE_TAG` | `(1 &lt;&lt; 8)` | Whether a tag is required to be specified when creating a thread in a forum or media channel. Tags are specified in the thread's applied_tags field. |
| `HIDE_MEDIA_DOWNLOAD_OPTIONS` | `(1 &lt;&lt; 12)` | When set hides the embedded media download options. Available only for media channels. |

### `ChannelType`

&gt; Used in SetGuildChannelMemberInt third parameter. Below channel type values are copied from DPP (v10.1.5)

| Member | Value | Description |
|--------|:-----:|-------------|
| `CHANNEL_TEXT` | `0` | A text channel within a server. |
| `DM` | `1` | A direct message between users. |
| `CHANNEL_VOICE` | `2` | A voice channel within a server. |
| `GROUP_DM` | `3` | a direct message between multiple users ⚠️ **Deprecated:** this channel type was intended to be used with the now deprecated GameBridge SDK. Existing group dms with bots will continue to function, but newly created channels will be unusable. |
| `CHANNEL_CATEGORY` | `4` | An organizational category that contains up to 50 channels. |
| `CHANNEL_ANNOUNCEMENT` | `5` | A channel that users can follow and cross-post into their own server. |
| `CHANNEL_STORE` | `6` | A channel in which game developers can sell their game on Discord. ⚠️ **Deprecated:** Store channels are deprecated by Discord. |
| `CHANNEL_ANNOUNCEMENT_THREAD` | `10` | A temporary sub-channel within a `GUILD_ANNOUNCEMENT` channel. |
| `CHANNEL_PUBLIC_THREAD` | `11` | A temporary sub-channel within a `GUILD_TEXT` or `GUILD_FORUM` channel. |
| `CHANNEL_PRIVATE_THREAD` | `12` | A temporary sub-channel within a `GUILD_TEXT` channel that is only viewable by those invited and those with the `MANAGE_THREADS` permission. |
| `CHANNEL_STAGE` | `13` | A "stage" channel, like a voice channel with one authorised speaker. |
| `CHANNEL_DIRECTORY` | `14` | The channel in a hub containing the listed servers. \[link](https:) |
| `CHANNEL_FORUM` | `15` | Forum channel that can only contain threads. |
| `CHANNEL_MEDIA` | `16` | Media channel that can only contain threads, similar to forum channels. |
